# 鲸鲸插件仓库

在 DSH 中管理 [DSH-Plugins](https://github.com/ccl4-56-23-5/DSH-Plugins) 的插件。入口位于左上角“使用统计”下方，当前版本 **1.2.2**。

## 功能

- 用卡片查看 GitHub 仓库已发布插件及本地已安装插件的名称、图标、说明和版本。
- 发现未安装插件，安装、更新、停用和卸载插件，保留已有配置与停用状态。
- 检测宿主入口与安装版本，显示运行状态。
- 先显示本地缓存，再从 GitHub 刷新目录；断网时继续查看缓存。
- 展示最近操作、完整诊断与安装结果。

目录缓存保存在 `$DSH_HOME/repo-manager/catalog-v1.json`，安装源包也保存在 `repo-manager` 目录。已安装插件可能依赖这些源包，请保留正在使用的文件。

## 安装与更新

首次安装：从 [Release](https://github.com/ccl4-56-23-5/DSH-Plugins/releases/tag/repo-manager-v1.2.2) 取得 TGZ，在 DSH 插件管理中添加。Windows ZIP 包含 TGZ、安装说明和 SHA-256 清单。

更新插件：打开仓库，点击“检测状态与更新”，找到插件卡片，选择“更新插件”并确认。确认内容直接显示在该插件卡片内；操作区依次显示下载、安装与结果核对。

安装完成后，管理器读取宿主版本和本地源包哈希。结果暂时无法核实时显示“待核对”，可查看操作记录和诊断。自更新导致页面重载后，管理器会根据目标版本与哈希恢复操作结果。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 绿色 | 已核对当前发布版本，所有宿主入口 active |
| 黄色 | 运行正常，有可用更新 |
| 红色 | 宿主入口缺失或处于非 active 状态 |
| 灰色 | 未安装、已停用或状态尚未确认 |

下载来源为本仓库的正式 Release，安装前核对版本，下载后检查大小、哈希与包身份。宿主要求重启时，界面会提示安排重启。控制桥和仓库管理器自身的停用请在 DSH 原生插件页操作。

## 故障处理

提示本地安装源不存在时，按诊断中的路径恢复源包，或通过 DSH 重新安装对应插件。展开完整日志可查看 ENOENT 等错误的具体位置。

## 开发

要求 Node.js 22 或以上。客户端源文件为 `src/client.js`，构建时加入图标并生成 `lib/client.js`。

```sh
node --test test/manager.test.mjs test/cache.test.mjs test/health.test.mjs test/operations.test.mjs
node scripts/build-release.mjs
```

[验证记录](VALIDATION.md)。界面设计参考 [dsh-market](https://github.com/dsh-market/dsh-market)。

## 发现与卸载

打开页面会在后台检查指定 GitHub 仓库的全部正式 Release；新发布的合规插件也会自动出现，无需更新内置名单。选择“仓库未安装”查看可安装插件，只有通过发布清单与 SHA-256 验证的安装包可安装。缓存或网络失败会明确显示检查状态。

市场只展示 ccl4-56-23-5/DSH-Plugins 的插件，已安装、仓库未安装、可更新、已启用的计数与筛选均限定在此仓库。其他本地或第三方插件不会进入列表，也不能通过此市场启停或卸载；请在 DSH 原生插件页管理。旧版页面缓存中的“仅本地安装”条目在读取时自动排除。仓库新发布的合规插件仍通过 Release 动态发现，无需写入内置名单。卸载仍保留用户数据，保护管理器及控制桥。
