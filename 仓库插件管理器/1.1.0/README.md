# 鲸鱼娘插件仓库1.1.0

管理[ccl4-56-23-5/DSH-Plugins](https://github.com/ccl4-56-23-5/DSH-Plugins)中的DSH插件。左上角“使用统计”下面打开“鲸鱼娘插件仓库”。

## 本版变化

进入页面先显示上次浏览快照和内置插件卡片，再从宿主读取本地安装状态，并在后台检查GitHub。网络慢或离线时保留列表，明确显示后台刷新、缓存时间或失败原因。首次使用也显示5张内置插件卡片，未查到的版本显示“待检查”。

成功检查的发布列表写入DSH_HOME/repo-manager/catalog-v1.json，宿主重启后可恢复；浏览器只保存用于展示的轻量快照。安装状态始终从DSH读取，缓存不触发安装，也不代替安装前的远端版本、包身份和SHA-256校验。坏缓存自动回退，刷新失败不覆盖上一次完整列表；同一时刻只进行一次远端刷新。

支持搜索、已安装/可更新筛选、查看发布说明、安装更新、启用停用及操作记录。5种原版透明图标随包内置。UI由DSH参与设计实现，保留鲸鱼娘正面购物车logo。

## 安装与更新

[下载Release](https://github.com/ccl4-56-23-5/DSH-Plugins/releases/tag/repo-manager-v1.1.0)。Windows ZIP内含TGZ与说明，无额外运行时依赖。

已安装用户可在DSH的“鲸鱼娘插件仓库”中点击“检查更新”，找到本插件后选择“更新插件”并确认；首次安装可在DSH原生“插件→添加插件”中使用Release TGZ地址。安装通过DSH官方插件管理器执行。如宿主提示需重启，保存当前工作后再自行重启。

## 数据与安全边界

仅访问指定仓库的正式Release，不请求GitHub令牌，不发送会话内容。安装前重新检查目标版本，校验下载大小、SHA-256和包内名称版本；发布变化时要求重新确认。保留插件用户配置与更新前停用状态，不自动降级。操作互斥并使用幂等ID；失败、配置覆盖与需重启状态独立显示。本版仅服务本机DSH桌面。

## 开发与验证

Node22及以上，无第三方运行时依赖。客户端源码为src/client.js；构建时注入图标生成lib/client.js。

`node --test test/manager.test.mjs test/cache.test.mjs`运行后端行为测试；`node scripts/build-release.mjs`构建TGZ与清单。

缓存测试覆盖冷启动非阻塞、并发刷新去重、重启恢复、网络失败保留、坏缓存回退与安装前复验。UI与实机验收范围见VALIDATION.md。

设计参考[dsh-market](https://github.com/dsh-market/dsh-market)，代码独立实现。

运行检测：红灯=宿主入口运行异常；黄灯=运行正常但待更新；绿灯=运行正常且最新版；灰色=停用、未安装或尚待确认。卡片内可查看原因并更新，页面每10秒刷新运行状态。检测覆盖宿主加载状态，不替代业务功能实测。
