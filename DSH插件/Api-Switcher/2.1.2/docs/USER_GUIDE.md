# 使用指南

## 入口与模型切换

在聊天输入框发送按钮旁点击当前模型名称。菜单按供应商分组，只列出启用的供应商及其已启用模型；供应商启用但没有勾选模型时不会出现可选模型。

选择模型会更新当前会话下一次请求的来源，并保存新会话默认模型；已开始的请求与其他旧会话不会被统一改写。推理强度可按模型支持范围选择，模型能力来自DSH与供应商配置。

## 搜索

菜单顶部搜索模型名称、模型ID、供应商名称或ID。例如`deepseek flash`、`apiyi gpt mini`。多个关键词用空格分隔，所有关键词都需匹配；不区分大小写，支持全角字符和省略模型ID中的短横线、点、下划线等分隔符。

搜索会展开有匹配模型的分组；清空后恢复搜索前的折叠状态。结果计数基于已启用模型，不是供应商公开目录总数。无匹配时可一键清空，或进入“管理供应商”启用其他模型。本地搜索不访问模型API。

打开菜单后焦点进入搜索框。上下方向键进入结果列表，回车选择，Esc关闭。中文输入法合成过程中不会拦截方向键，搜索框中的Home/End保留文本编辑行为。

## 供应商配置

点击“管理供应商”，或从“插件管理→api-switcher→设置”进入。左侧选择供应商，右侧包含“连接设置”和“模型管理”。

| 字段 | 说明 |
| --- | --- |
| 名称 | 界面显示名称 |
| 来源ID | 小写字母开头，仅小写字母、数字、短横线，最多64字符 |
| API地址 | 完整HTTP/HTTPS基础地址，不能带凭据、查询参数、片段 |
| 协议 | 选择与供应商接口相符的三种支持协议之一 |
| 密钥 | 填写新Key；留空保留已经保存的Key |
| 网站 | 用于自动获取供应商logo，与API基础地址可不同 |

来源ID用于配置与凭据关联。更换已有来源ID会形成新的来源，不是重命名；只改变名称可直接编辑显示名称。DSH原生账号的认证由DSH管理，本插件只管理其名称、网站、启用状态与模型范围。

开启或关闭供应商、修改模型勾选与连接信息后，点击“保存配置”。未保存草稿不直接写入DSH。保存之后自动获取网站图标；失败时使用名称图标，可点击“获取图标”重试。

## 模型管理

“同步模型”通过当前协议与API地址查询目录，也可手动添加模型。它不发送对话，但会访问供应商并按需要使用已保存Key。若草稿地址或协议已变更，需要重新输入该地址对应Key。

模型ID是请求中的实际标识，名称只用于显示。可编辑上下文窗口、最大输出、文本/图片输入、推理等级；这些字段是配置，不会自动检测模型真实能力。每个来源允许1至500个模型，ID不能重复，最大输出不能大于上下文窗口。

模型管理搜索用于从完整目录中查找名称/ID；勾选部分模型后保存。它与会话菜单搜索的范围不同：模型管理可找到尚未启用的模型。

## 连接测试与删除

“测试连接”经界面确认后发送要求回复`OK`的真实请求，最大输出256tokens、超时45秒。收到非空且正常完成的文本才视为成功；显示耗时与脱敏回复。不同来源的计费、最低消费和模型可用性由供应商决定。

只允许删除通过本插件创建的来源。删除前先将默认模型切到其他来源；删除保留共享Key以便回滚和其他配置使用。停用则保留全部配置，只改变此插件菜单的显示范围。

## 保存冲突

多个窗口同时编辑配置时，旧revision会被拒绝并提示刷新。先记录需要保留的草稿，刷新读取最新配置后重新提交；不要把冲突当作已保存成功。
