# 故事中控台 StoryDeck 0.8.0 测试版

世界书保存设定，万象星图展示条目和关系。两者共用灰蓝界面、导航、控件和固定布局，切换保留星图视角与草稿。各工作区共用世界书与条目开关，各对话保留自己的剧情进度、角色认知和事件。

## 安装与入口

在鲸鲸插件仓库打开“接收测试版更新”后检查更新，或下载 [测试版 Release](https://github.com/ccl4-56-23-5/DSH-Plugins/releases/tag/storydeck-v0.8.0) 中的Windows ZIP/TGZ。[稳定版 0.7.1](https://github.com/ccl4-56-23-5/DSH-Plugins/releases/tag/storydeck-v0.7.1) 继续保留。按DSH提示完成加载；此更新由用户手动安装。

- 点击右上角绳子上的大肥鱼，打开故事中控台；在中控台内切换“世界书”和“万象星图”。
- 世界书页提供导入、开关、剧情状态和检索预览；星图读取当前对话所属工作区的世界书，标题右侧按钮可扩大中控台。

## 世界书与星图

选择世界书后，每个条目都是一个球体星点，所有条目和关系显示在同一张图中。悬停预览正文，点击固定详情；详情包含原文来源、关系及关系依据。明确关系为实线，推定关系为虚线。支持类型筛选、搜索、鼠标滚轮或按钮缩放、拖动平移、键盘方向键和触屏操作；点击“适应”可重新看到整个星图，改变窗口大小时画布自动调整。

世界书为空时可在星图直接“新建世界书 → 创建并启用”；也可以在完整世界书管理导入RikkaHub或StoryDeck JSON。正文以世界书为单一来源，星图只保存关联元数据。同一工作区内的现有、新建或移入对话共用开关；不同工作区独立。未归入工作区的对话独立保存。停用条目保留星点，但不会返回给写作检索。

## AI整理与归档

1. 在星图选择目标世界书，输入零散设定。
2. 选择“公开设定”或“作者隐藏”，点击“AI整理归档”。
3. 插件通过DSH原生模型服务调用已配置的默认模型，整理条目、匹配已有设定并保存关系。界面显示所用模型，成功后跳到新增条目。

“AI梳理已有关系”只分析已有参考条目并补充关系，不复制或改写世界书正文。它不会清空输入框内尚未提交的草稿。

AI参考资料仅包含目标书在当前对话中已启用、通过作者隐藏/角色认知/剧情状态条件的条目；作者能看见星图，不代表隐藏资料会自动发给模型。单次最多参考60条、24000字符正文，超出预算的条目不会发送。每次输入最多12000字符，结果最多30条新设定、60条关系；使用模型的默认输出预算，最多12000 token。单次整理最长3分钟。

条目与关系保留连续来源原文；参考已有世界书正文时也记录来源条目。推断必须保留不确定性。AI结果仍应由作者检查，最新归档批次可撤销；已有后续修改时改用条目开关，避免撤销覆盖后续剧情。

新条目归入所选世界书；若该书在当前工作区已启用，新条目也会在本工作区启用。归档不会替其他工作区开启新条目，也不会重新开启整理期间被关闭的书。世界书正文是本机公共书库，选择同一本书的其他工作区可以看到其新增内容，但开关、关系网与剧情进度按各自范围保存。

## 保存与恢复

整理任务在调用模型前落盘，同一任务ID重发不会重复调用或归档。界面刷新后会读取未完成任务；保存回执不确定时先重新读取。宿主中断后不能确认的任务显示“待核对”，不会自动再次调用模型。输入草稿和失败记录保留；“重新整理”会发起新模型调用。

JSON格式、未知关系端点、重复名称、无原文依据、输出截断或模型错误均不会写入书库。新条目及关系原子保存，不执行AI给出的代码或工具。归档追加条目，保留现有正文、状态、认知与事件；原有书的字段结构不变。

## 格式与数据

支持StoryDeck及RikkaHub原生世界书。RikkaHub既有未知字段与顺序保留，新条目同步进原生导出。作者隐藏的新RikkaHub条目携带storydeckVisibility扩展标记，原生enabled为关闭；在DSH重新导入时恢复隐藏标记。

数据仍在DSH_HOME/storydeck/worldbook-v1.json（默认 ~/.dsh/storydeck/worldbook-v1.json），内部升级schema4。首次成功写入前备份原schema1/2/3字节；只读不改用户文件。写锁、原子替换、版本校验和操作去重保护并发更新。支持单书4MiB、3000条目，数据文件总量32MiB。既有世界书的状态字段及正文编辑继续沿用原规则；使用中的书请另存新ID。
