# StoryDeck 0.3.1 验证范围

2026-10-26。

本次修复0.3.0角色图中两条手臂从同一肩膀分叉的结构错误。人工放大检查分别追踪左右肩膀、上臂、肘部、前臂、手腕和手掌；左臂从画面左肩横过胸前连接下方握绳的手，右臂单独上举连接上方握绳的手。衣袖保持连续，腕部袖口各自对应一只手。手部和握持段绳子直接画在PNG中，界面仅接上方一段绳子，不再叠线穿过手指。该绘画结构检查与自动交互测试分开记录。

- 正则工作进程的启动等待单独限制为5秒，启动完成后才计算500ms默认匹配时限；恶意正则仍在有时限的工作进程中终止。避免Windows慢启动在执行正则前耗尽匹配预算。
- 23项Node回归通过：世界书、状态和认知条件、幂等性、版本冲突、事件撤回、持久化、RikkaHub完整字段往返、多书与条目开关、A/B选择和剧情状态隔离、旧数据迁移备份、正则超时及错误。
- 独立React/Edge及临时世界书验证通过：右上角shell.overlay入口，旧输入框按钮移除，35px宽、约49.1px高，面积约为105px审核预览的1/9；遵守32px标题栏避让，360px窄屏不溢出。实际worldbook路由返回的mascot PNG与打包源图逐字节一致。
- 动画验证通过：绳顶为旋转支点，5.8秒周期，正负1.6度轻摆；悬停、键盘聚焦时暂停；系统减少动态效果时无动画。绳子的露出段绘制在头发前，手部保留遮挡。
- 交互验证通过：原生弹窗点击和Escape关闭、焦点返回、导入、多书勾选、条目检索控制、状态提交、会话切换关闭旧弹窗、取消草稿、清空后刷新。按宿主当前主视图的真实会话标记选择sessionId；切到其他主面板或没有当前会话时隐藏挂件。
- 宿主接口依据本机DSH 0.2.1-rc.3的布局与会话模块读取核对：shell.overlay、useSessions、usePanelInfo及retainedBy.mainView。隔离浏览器提供对应数据源，工具定义导入在路由测试中使用空替身，不据此宣称完整宿主工具集实测。
- 美术沿用用户审核的两头身灰蓝鲸鱼娘。插件原图标与设置页logo保留，新增透明RGBA挂件图、母版及设计/哈希记录。包内不包含用户设定、运行配置或本地维护规则。

用户指定后续自行从DSH插件页更新，因此本次不安装到运行中的DSH，不重启宿主；更新后真实桌面加载验收待用户手动完成。长期小说写作的模型语义验收不在本次入口修改范围内。远端CI、Release及下载哈希结果另存交付记录。
