# 故事中控台 StoryDeck 0.1.0

第一个子插件是世界书调度器：世界书保存设定，剧情记录状态，检索按状态和角色认知筛选条目。主包通过 Cordis 子插件挂载调度器，后续能力可沿同一边界扩展。

## 安装和入口

从 [GitHub Release](https://github.com/ccl4-56-23-5/DSH-Plugins/releases/tag/storydeck-v0.1.0) 下载 Windows ZIP 或 TGZ。在 DSH 插件管理器安装 TGZ，或使用命令：

```sh
dsh plugin --profile desktop add ./dsh-storydeck-0.1.0.tgz
```

桌面左侧“故事中控台”打开统一面板。也可在插件设置页打开。

## 开始使用

1. 世界书页载入修真示例，编辑后保存；也可导入自己的 JSON。
2. 剧情状态页选择世界书，填写名称并创建剧情。
3. 将要写作的 DSH 会话关联到该剧情。未关联的会话不读取世界书。
4. 在会话中写作。DSH 通过 `storydeck_context` 读取相关条目，通过 `storydeck_commit` 自动记录已发生的状态变化。
5. 检索预览页查看命中内容和作者可见的筛选原因；事件页可逐条撤回最新变化。

## 世界书与状态协议

世界书包含 `id/title/fields/initialState/entries`。字段类型为 `enum/string/number/boolean/tags`，枚举值的顺序也是范围比较的顺序。参考 [内置示例](lib/example.js)。

条目包含 `id/title/body/tags/visibility/always/when`：

- `public`：状态条件满足即可检索。
- `known`：还需出现在剧情的 `knownIds`。
- `author`：作者隐藏资料，模型检索工具永不返回。
- `when.all` 要求全部满足，`when.any` 要求至少一个满足；两者同时存在时同时生效。
- 条件支持 `eq/ne/in/contains/gte/lte`，不执行 JavaScript 或表达式字符串。
- `always` 只提高装入优先级，不绕过状态和认知条件。

先筛选允许访问的条目，再做关键词相关度排序及条数/字符预算。首版是本地确定性检索，不包含向量数据库或自动语义索引。使用中文字符匹配，复杂同义词需作者提供标签。

剧情与会话显式关联，同一本世界书可以派生多个独立剧情。新分支复制当前状态；不会自动推断 DSH 会话 fork 和正文重写的对应关系。已用于剧情的世界书不能被覆盖，修改请另存新 ID 并建立新剧情。

## 自动事件

事件需要最新全局 `revision`、`expectedStateRevision`、`certainty: confirmed`、`summary`、`source` 原文和 `patch`。允许 DSH 自动提交；不逐次要求用户确认。未发生的突破、别人境界、梦境和假设不应提交。插件验证结构、合法值、版本和幂等性；事件语义及来源正文由调用模型报告，插件不能独立保证模型理解正确。作者可在事件页检查并撤回。

事件不能更改世界规则或加入未定义字段，不能将作者隐藏条目标记为角色已知。仅可依次撤回最新未撤回事件，避免覆盖后续变化。

## 本地数据与边界

数据保存在 `$DSH_HOME/storydeck/worldbook-v1.json`，默认 `~/.dsh/storydeck/worldbook-v1.json`。停用或更新保留用户数据。支持导出完整本地 JSON 备份；首版只导入世界书，完整剧情备份恢复需要停用插件后由用户恢复原数据文件。

原子文件替换、文件写锁、全局及剧情版本校验防止覆盖。进程异常可能留下锁；先确认没有其他写入进程再人工处理，插件不会自行破坏遗留锁。

本插件控制自身检索工具的返回范围，不能清除模型预训练知识、已进入聊天的旧内容，或阻止其他文件工具读取用户授权的资料。隐藏条目不能靠提示词形成完整的系统访问隔离。每轮状态快照按当前 DSH 会话读取，未关联会话没有额外故事指令。

客户端是作者管理界面，展示完整世界书；模型工具只返回筛选后的内容。数据不会上传到 GitHub。安装后若 DSH 返回需重启，应在用户允许时重启，运行中的会话不应为安装验收而中断。
