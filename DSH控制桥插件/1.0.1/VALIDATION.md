# DSH 控制桥 1.0.1+2 验证记录

2026-11-28，Windows，DeepSeek Harness Desktop 0.2.3-alpha.2。

- 12 项 Node 回归通过。新增回归覆盖新版路由策略、正确和错误令牌、缺少令牌、跨站请求，以及桌面通道和品牌路由的宿主登录校验。
- Codex 的状态检查与工具调用沿用连接文件、Bearer 令牌和协议版本 1。DSH 安装清单使用版本号 `1.0.1`，发布名称使用累计交付版本 `1.0.1+2`。
- 通过 DSH CLI 安装并正常重启后，原 Codex MCP 客户端读取状态、会话、模型、工作区、插件和桌面 DOM 快照。新建答复测试会话，以 `answerOnly` 发起请求并读取成功结束的实际回复“喵，DSH-BRIDGE-OK”。实测桌面打开该会话并回读选择，随后恢复原会话、归档测试会话。
- 实机 HTTP 检查中，正确令牌返回 200，缺少或错误令牌返回 401，跨站 Origin 返回 403，仅有桥令牌的桌面轮询返回 401。实际 DSH 桌面仍可轮询并完成快照和打开会话操作。
- 桌面插件设置页实测加载 512×512 像素透明 Logo，显示为 96×96。
- 安装后比较了 DSH 桌面档案的直接依赖，只有 `dsh-control-bridge` 指向新包。版本、协议及测试覆盖范围见上述记录，第三方扩展未逐项实测。
