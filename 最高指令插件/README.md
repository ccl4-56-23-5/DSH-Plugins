# 最高指令

<p align="center"><img src="1.1.2/lib/assets/logo.png" width="192" alt="最高指令 logo"></p>

在 DSH 插件页编辑全局系统提示词。支持多行输入、Ctrl+Enter 保存和即时启停，原样保存换行、花括号与空白；正文上限 32 KiB。

当前版本 **1.1.2**，包名 `dsh-top-directive`。
