# 最高指令插件

当前版本：**1.1.1**；DSH内部包名：`dsh-top-directive`。

在DSH插件页编辑全局初始提示词，支持多行输入、Ctrl+Enter保存、即时开关和原文热更新。正文在DSH身份段之前进入system消息，保留换行、花括号和空白，上限32KiB。
