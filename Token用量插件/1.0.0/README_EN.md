# Usage Statistics: Fish Edition 1.0.0

A customized replacement for HaoyueQin/dsh-usage-statistics-panel 0.3.2. The original package identity, statistics database, event collector, settings and sidebar entry are preserved.

The dashboard keeps the yearly square heatmap, stacked daily bars, model/provider donuts and stats-line options. The cache-rate curve, point markers, percentage axis and curve legend are removed. The misleading sessions label is corrected to ended turns. A transparent character logo and a quieter dashboard header complete the customization.
