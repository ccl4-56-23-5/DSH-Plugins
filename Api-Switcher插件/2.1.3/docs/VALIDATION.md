2.1.3主要补充图文说明、市场截图声明和仓库元数据；运行逻辑沿用2.1.2，仅更新版本号。本次26项本地自动测试全部通过；源码检查覆盖58个公开源文件、42处本地文档链接和4张截图。TGZ解包后36个文件逐项校验通过；Windows ZIP内27个清单项及4张截图校验通过。GitHub持续集成对Windows/Linux与Node20/24四种组合运行相同的离线检查，远程结果以仓库Actions为准。

新增检查覆盖截图清单的1至8张限制、相对路径边界、文件存在性和格式。文档中每个本地链接均由项目检查器验证，发布导出按白名单排除`.work/`、用户配置和凭据。

4张图使用实际前端组件与隔离示例数据，在本机浏览器完成拍摄和视觉检查，说明见[截图说明](screenshots/README.md)。这不是DSH原生桌面验收：本次查看时Windows锁屏，因此未继续操作DSH，未重启宿主，也未安装覆盖当前正在使用的2.1.2。

## 既有验证与限制

2.1.2曾完成26项本地自动测试、29个包文件逐项校验及实际DSH安装；安装前后凭据、提示词和模型启用范围的文件哈希一致，其他8个插件声明依赖保持一致。2.1.0曾完成11项桌面检查。这些历史结果不代替2.1.3的原生窗口或供应商实测。

测试使用本地fixture，覆盖保存/回滚/并发、来源与模型开关、一次性预配置、搜索归一化/分组/计数/清空/键盘、插槽卸载、弹窗portal、HTTPS图标及HTTP边界。程序打包、安装、演示截图都不等于所有供应商与模型已实测。

本次没有委派DSH模型，没有发送付费模型请求。API易Key仍由用户在真实设置页中填写，示例认证状态不反映个人账户配置。
