# 安全说明

## 凭据与数据

密钥通过DSH凭据服务保存，默认位置为`%USERPROFILE%\.dsh\.credentials.yaml`；这是DSH管理的本机文件，本插件不提供额外的加密存储承诺。状态接口只返回是否已配置及凭据引用，不回显Key。空密钥输入框表示保留现有Key，不能据此判断未配置。

供应商连接与模型能力由DSH设置服务管理。插件仅在`%USERPROFILE%\.dsh\api-switcher\state.json`保存启用范围、网站、显示名称、收藏和自建来源标记，网站图标缓存在相邻`icons/`目录。部署备份也在该用户目录中，不能上传到公共仓库。

来源地址或协议改动后的模型发现要求重新输入对应Key，避免将现有凭据发送到未保存的新地址。删除来源保留共享凭据，供其他配置和回滚使用；需要删除Key时，使用DSH凭据管理。

## 网络边界

- 插件HTTP接口只接受本机Host及同源请求；拒绝跨站请求，写入要求JSON且最多512KiB。
- API地址仅支持HTTP/HTTPS，不允许嵌入用户名、密码、查询参数或片段。本地HTTP接口可用于Ollama；远程接口建议使用HTTPS。
- 自动网站图标仅通过HTTPS获取，不附带API密钥；限制响应大小、重定向与下载时间，检查解析IP并固定连接，过滤SVG可执行内容。
- 为兼容本机Clash等代理，对公开域名的fake-IP映射有例外处理；这不是完整网络沙箱。
- 连接测试会发送真实模型请求，界面提示可能计费。后台接口假定调用者是可信的本机DSH客户端，不对有本机执行权限的恶意程序提供隔离保证。

## 发布检查

仓库禁止包含`.credentials.yaml`、`.env`、profile配置、`state.json`、部署备份、聊天记录、临时日志或用户Key。示例使用占位说明，不提供可用密钥。安装包不运行npm生命周期脚本；校验值用于检测文件变化，不代替发行者身份认证。

## 报告问题

普通缺陷可提交GitHub Issue。安全问题请先通过仓库所有者提供的私密渠道报告；未提供私密渠道时，公开Issue仅写“请求安全联系渠道”，不要发布漏洞细节或凭据。报告包括受影响版本、必要的复现步骤和脱敏结果；维护者尚未承诺响应时限。
