# 模型输入能力核对

2026-10-11核对全部236个内置条目：MiMo3个模型均支持文字和图片。API易233个条目中，62个图片、7个文字、164个待确认。未知不代表不支持；默认交给DSH处理，也可在模型编辑器中按供应商文档手动设置。

MiMo依据[官方图片输入文档](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/multimodal-understanding/image-understanding)，支持图片URL和Base64。API易能力依据DSH0.2.0-rc.2内置pi-ai原厂目录的完整模型ID精确匹配，多个匹配须一致；不推断别名或thinking后缀。每项保留inputEvidence。此依据是模型元数据核对，不等于API易每条线路已实测。API易公开目录此次返回403，因此保留既有模型ID范围，没有宣称目录已在线刷新。

同步接受DSH的inputModalities，归一化为配置input。自动模式更新已存在模型的已知输入能力；新模型默认停用。同步不覆盖名称、启用范围或手动能力，上游不提供能力时不降级已有声明。

升级只迁移本插件管理、端点精确匹配官方模板、模型ID在内置目录且旧值恰为text的条目；手动标记和其他供应商不变。旧版本没有记录手动来源，无法区分同值的旧手动text与模板text。此有限歧义通过一次性迁移解决；升级后手动选择始终优先。未知旧模板去掉强制text，已知项补入核对能力。只在配置写入成功后记录迁移标记。

模型能力声明不证明实际接口、账户额度、工具调用和每种图片格式均可用。应分别验证文字连接与图片请求。
