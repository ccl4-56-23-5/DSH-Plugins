# 品牌资产

## 设计

api-switcher使用蓝青色S形双切换箭头与右下角鲸鱼娘。2.1.1按用户最新要求，将角色原宽、高各放大4倍作为重绘目标；这会覆盖更多箭头区域，替代早期四分之一边长小三角的尺寸要求。

角色沿用用户指定形象：深蓝至浅蓝发梢、蓝眼、白色褶边头饰、右侧蓝蝴蝶结、鲸尾形发束、笑脸及两只小手。保留原切换符号风格、右下角位置和透明背景，不添加白底、圆形徽章或文字。

## 文件

| 文件 | 用途 |
| --- | --- |
| `assets/logo-master.png` | 高分辨率RGBA透明母版，仅随源码发布 |
| `lib/assets/logo.png` | 512×512，设置界面 |
| `lib/assets/icon.png` | 256×256，插件管理图标，低于256KiB |

生成采用Codex内置imagegen，以2.1.0透明logo和用户原图为参考；导出仅使用常规高质量缩放。最终可见尺寸由生成工具重绘确定，并非对原角色像素块做精确的机械缩放。母版与导出的SHA256记录在`assets/branding.json`，原始生成结果保留于本机生成目录。

## 生成要求摘要

“保留现有蓝青色双箭头；将右下角角色按原宽、高各4倍放大，而非面积4倍。沿用角色身份和头部加双手构图，不增加全身或大尾巴；透明RGBA，箭头之间也透明，无白色面板、文字或背景阴影。”

素材来源与权利说明见[第三方声明](../THIRD_PARTY_NOTICES.md)。供应商logo为运行时网站图标，与本插件品牌图标分开管理。
