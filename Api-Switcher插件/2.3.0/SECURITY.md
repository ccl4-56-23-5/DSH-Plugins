# 凭据与安全

## 本地数据

密钥由 DSH 凭据服务管理，默认保存在 `%USERPROFILE%\.dsh\.credentials.yaml`。插件状态接口返回配置状态和凭据引用。密钥框留空会保留已有密钥。

连接与模型能力保存在 DSH 设置中；启用范围、网站、显示名称、收藏等元数据位于 `%USERPROFILE%\.dsh\api-switcher\state.json`，图标缓存在相邻的 `icons/`。部署备份位于同一用户目录。分享诊断时应去除密钥、用户配置和聊天内容。

更换地址或协议后，模型发现需要重新输入目标地址的密钥。删除供应商时保留共享凭据，需要移除密钥时可通过 DSH 凭据管理操作。

## 网络与接口

- HTTP 接口限定本机 Host 与同源请求；写入使用 JSON，请求上限 512 KiB。
- API 基础地址支持 HTTP/HTTPS，字段中禁止嵌入用户名、密码、查询参数和片段。远程接口建议使用 HTTPS。
- 图标通过 HTTPS 获取，带有响应大小、重定向、下载时间和解析 IP 检查，并过滤 SVG 可执行内容。图标请求不携带 API 密钥。
- 本机代理的公开域名 fake-IP 映射有兼容处理。
- 连接测试经界面确认后发送真实模型请求，可能产生费用。

接口面向可信的本机 DSH 客户端。

## 发布与报告

发行文件包含程序、文档和公开示例。提交前检查密钥、profile、运行数据和部署备份；下载后可用 SHA-256 清单核对完整性。

普通缺陷请提交 GitHub Issue，附版本、复现步骤和脱敏结果。报告安全问题时，先通过仓库所有者提供的私密渠道联系；若没有联系方式，可先开 Issue 请求安全联系渠道，漏洞细节与凭据通过私密方式发送。
