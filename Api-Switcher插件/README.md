# api-switcher

<p align="center"><img src="2.3.0/lib/assets/logo.png" width="192" alt="api-switcher logo"></p>

在一个设置页管理 API 供应商，在会话输入框旁搜索和切换模型。

- 按供应商分组显示模型，分别控制供应商和模型的启用范围。
- 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages。
- 配置文本与图片输入、上下文容量、输出预算和思考参数。
- 提供 API 易和小米 MiMo 模板、模型目录同步和连接测试。

当前版本 **2.3.0**。
