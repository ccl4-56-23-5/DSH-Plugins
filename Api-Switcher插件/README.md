# api-switcher 2.3.0

<p align="center"><img src="2.3.0/lib/assets/logo.png" width="192" alt="api-switcher透明logo"></p>

在一个设置页管理供应商，在发送按钮旁搜索和切换模型。按供应商地址、协议与模型匹配真实思考能力，保留已有配置和自定义参数。

- MiMo显示思考开关；已确认的GPT/Claude组合显示其支持的档位。
- 未确认的第三方组合不根据同名上游模型猜测能力。
- 需要原生协议的模型可添加独立来源，共用原凭据引用，原来源保持。
- 65项回归、145种真实宿主请求映射与真实API对照通过；最终版重启加载后的桌面验收待完成。
