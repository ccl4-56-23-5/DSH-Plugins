# DSH插件

DSH桌面插件集合。每个项目只保留当前最新版的源码和安装包。

| 插件 | 当前版本 | 功能 | 下载与安装 |
|---|---|---|---|
| [最高指令插件](最高指令插件/README.md) | 1.1.1 | 全局初始提示词，多行输入、即时开关、原文保存 | [安装包](https://github.com/ccl4-56-23-5/DSH-Plugins/releases/tag/top-directive-v1.1.1) · [安装指南](最高指令插件/1.1.1/docs/INSTALLATION.md) |
| [Api-Switcher插件](Api-Switcher插件/README.md) | 2.1.3 | 多供应商管理、模型选择、搜索和连接测试 | [安装包](https://github.com/ccl4-56-23-5/DSH-Plugins/releases/tag/api-switcher-v2.1.3) · [安装指南](Api-Switcher插件/2.1.3/docs/INSTALLATION.md) |

## 目录

```text
DSH-Plugins/
├─ 最高指令插件/1.1.1/
└─ Api-Switcher插件/2.1.3/
```

点击项目名称查看功能图文、使用说明和开发文档。最高指令安装文件位于其版本目录；Api-Switcher安装文件位于其版本目录的`dist/`。也可从上表的Release入口下载。

Codex控制DSH的插件单独保存在[Codex-Plugins](https://github.com/ccl4-56-23-5/Codex-Plugins)。

## 版本与验证

默认分支和Release仅保留各插件最新版；Git提交历史用于追溯。版本更新时替换本项目版本目录，更新文档、下载链接与SHA-256，保留其他项目。

本次仓库整理核对目录、安装包和源文件哈希；实际运行验收范围分别见[最高指令验证记录](最高指令插件/1.1.1/docs/VALIDATION.md)和[Api-Switcher验证记录](Api-Switcher插件/2.1.3/docs/VALIDATION.md)。
